# Nova — هوش مصنوعی شخصی

## شروع سریع
1. فایل **nova-ai.html** را در **Chrome** باز کن (نه داخل پیش‌نمایش اپ Claude).
2. ⚙️ تنظیمات ← کنار هر سرویس «🔑 گرفتن کلید» را بزن، کلید را بگذار.
3. «🔎 تست همهٔ سرویس‌ها» را بزن. اگر چیزی کار نکرد، دقیقاً می‌گوید چرا (کلید، مدل، اینترنت/فیلتر، CORS).

## چند هوش مصنوعی پشت‌سرهم
هر سرویسی که کلید داشته باشد فعال می‌شود. اگر یکی محدود شد (429) یا قطع بود، یک دقیقه کنار می‌رود و خودکار سراغ بعدی می‌رود.
«نامحدود» واقعی وجود ندارد؛ این روش فقط احتمال گیر کردن را کم می‌کند.

## سرویس‌ها
Groq، Cerebras، OpenRouter، Google Gemini، Mistral، SambaNova، DeepSeek، Claude (Anthropic، پولی)، OpenAI (پولی)،
Pollinations (بدون کلید، آزمایشی)، Ollama (روی کامپیوتر خودت) و «➕ سرویس سفارشی» برای هر سرویس سازگار با OpenAI یا Anthropic.
نام مدل‌ها گاهی عوض می‌شود: در تست، مدل‌های موجود نشان داده می‌شوند و با یک لمس انتخاب می‌شوند.

## Ollama (مدل روی کامپیوتر خودت)
Ollama را با `OLLAMA_ORIGINS=*` اجرا کن و در تنظیمات تیک «فعال» را بزن.

## محتویات پوشه
- `nova-ai.html` — نسخهٔ تک‌فایل، بدون سرور (پیشنهادی)
- `index.html` + `server.js` + `manifest.json` + `sw.js` + آیکون‌ها + `package.json` — نسخهٔ سرور (PWA قابل نصب)
- `shim.js` — منبع بخش اتصال به هوش مصنوعی

## نسخهٔ سرور (اختیاری)
`ANTHROPIC_API_KEY=... npm start` یا `PROVIDER=openai OPENAI_BASE_URL=... MODEL=... npm start` — سپس http://localhost:3000

نکته: کلیدها فقط روی همان دستگاه در مرورگر ذخیره می‌شوند. این صفحه را با کلید داخلش جایی عمومی منتشر نکن.
